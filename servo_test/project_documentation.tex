\section{Document Scope}
This document describes the servo-control subsystem implemented in:
\begin{itemize}[leftmargin=*]
  \item \texttt{servo\_test/test\_focus.py}
\end{itemize}
within the repository \texttt{hailo-rpi5-examples}. It focuses on terminal-based control of a 360-degree (continuous rotation) servo using a PCA9685 PWM driver connected to Raspberry Pi 5 GPIO I2C pins.

\section{Project Overview}
\subsection{Purpose}
Provide a low-latency, terminal-driven test utility to:
\begin{itemize}[leftmargin=*]
  \item Drive continuous servo speed and direction.
  \item Calibrate neutral pulse width to stop unwanted drift/spin.
  \item Validate PCA9685 channel behavior and servo response.
\end{itemize}

\subsection{Current Status}
The control script uses direct pulse-width output (microseconds) instead of high-level continuous-servo abstractions to improve neutral calibration accuracy.

\section{System Architecture}
\subsection{Signal Chain}
\begin{enumerate}[leftmargin=*]
  \item User presses key in terminal.
  \item Script parses key input in raw TTY mode.
  \item Script computes target pulse width in microseconds.
  \item Pulse converted to PCA9685 16-bit duty cycle.
  \item PCA9685 outputs PWM on selected channel.
  \item Continuous servo rotates according to PWM pulse width.
\end{enumerate}

\subsection{Control Model}
Let:
\begin{itemize}[leftmargin=*]
  \item $n$ = neutral pulse width (\textmu s)
  \item $r$ = speed range (\textmu s)
  \item $s \in [-1,1]$ = normalized speed command
\end{itemize}
Then:
\[
\text{pulse\_us} = \mathrm{clamp}(n + s\cdot r,\ \text{min\_pulse\_us},\ \text{max\_pulse\_us})
\]

Duty cycle conversion at frequency $f$:
\[
\text{duty\_cycle} = \left\lfloor \frac{\text{pulse\_us}}{1{,}000{,}000/f} \cdot 65535 \right\rfloor
\]

\section{Build and Execution}
\subsection{Dependencies}
Install the Python package used by this script:
\begin{lstlisting}[language=bash]
pip install adafruit-circuitpython-pca9685
\end{lstlisting}

\subsection{Run Command}
\begin{lstlisting}[language=bash]
python3 servo_test/test_focus.py --channel 9
\end{lstlisting}

\subsection{Calibration Workflow}
\begin{enumerate}[leftmargin=*]
  \item Start script and ensure servo is connected to target PCA9685 channel.
  \item Press \texttt{SPACE} to set speed command to zero.
  \item Adjust \texttt{[} and \texttt{]} until servo fully stops.
  \item Note reported neutral value (\texttt{Neutral=...us}).
  \item Re-run with fixed neutral:
\end{enumerate}
\begin{lstlisting}[language=bash]
python3 servo_test/test_focus.py --channel 3 --neutral-us <value>
\end{lstlisting}

\section{Troubleshooting Notes}
\subsection{Observed Field Issue}
A specific servo was reported to spin continuously across multiple PCA9685 channels while another servo behaved correctly on the same setup. This strongly indicates a servo-specific issue (internal controller fault, trim drift, or wiring at servo lead) rather than a single PCA9685 channel software problem.

\subsection{Recommended Isolation Test}
\begin{enumerate}[leftmargin=*]
  \item Use same PCA9685 channel and same cable, swapping only the servo.
  \item Compare behavior at identical neutral pulse.
  \item If only one servo fails, replace or physically trim-calibrate that servo.
\end{enumerate}

\section{Limitations}
\begin{itemize}[leftmargin=*]
  \item Continuous servos do not have position feedback; control is speed/direction only.
  \item Neutral pulse is unit-specific and may drift with voltage/load/temperature.
  \item PCA9685 may hold last PWM state until explicitly changed or power-cycled.
\end{itemize}

\section{Safety and Operating Guidance}
\begin{itemize}[leftmargin=*]
  \item Keep load removed during initial calibration.
  \item Use a stable external servo power rail with shared ground to PCA9685/RPi.
  \item Avoid stalling servo at high command for extended periods.
  \item Keep emergency stop command (SPACE) readily accessible.
\end{itemize}
